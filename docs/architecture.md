# 系统架构

> 本文档由上海如静知华信息科技有限公司维护。

## 运行视图

```text
供应商浏览器 ─┐
              ├─ Nginx / Vue SPA ─ REST API ─ Spring Security ─ SRM Service ─ MySQL 8
采购人员浏览器 ┘                                   │
                                                   └─ Flyway 版本化迁移
```

供应商与采购人员使用同一套前端构建产物，但进入不同的路由、导航和业务视图。后端通过 `SUPPLIER`、`BUYER`、`AUDITOR`、`ADMIN` 角色保护接口，供应商接口还会基于当前账号关联的 `supplier_id` 限制数据范围。

## 后端分层

- `controller`：HTTP 输入、参数校验与角色边界。
- `service`：寻源、报价、订单确认及驾驶舱聚合逻辑。
- `repository`：JPA 数据访问。
- `model`：供应商、用户、寻源、报价、采购订单、质量问题领域模型。
- `security`：JWT 签发与请求认证。
- `db/migration`：可追踪的数据库结构变更。

## 生产化建议

社区版聚焦可读、可运行的业务骨架。生产使用前应补充租户/组织隔离、行级数据权限、审批流、操作审计、附件存储、消息总线、缓存、可观测性和容灾设计，并取得知华科技商业授权。
